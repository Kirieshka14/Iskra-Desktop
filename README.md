# Iskra Desktop (macOS DMG, Windows EXE & Linux DEB)

Официальный открытый десктопный клиент платформы интерактивного сторителлинга **Iskra**, созданный на базе **Electron** под свободной лицензией **GNU AGPLv3**.

Этот репозиторий предназначен для сборки официального приложения Iskra под macOS, Windows и Linux, а также для создания пользовательских модов сообщества.

---

## Возможности клиента

* 🖥 **Нативное окно без рамок браузера**: Чистый тёмный интерфейс `#0d0f12`, плавная аппаратная прокрутка, кастомные аккуратные скроллбары.
* ⚡ **Автоматическая инъекция Client Key**: Заголовок `X-Iskra-Client-Key` автоматически передаётся во все сетевые запросы к API.
* 🔒 **Полная синхронизация**: Все диалоги, персонажи, история и единый баланс сообщений синхронизируются в реальном времени с веб-версией.
* 🛎 **Интеграция с System Tray**: Иконка в трее с быстрым восстановлением окна, перезагрузкой и управлением фоновым состоянием.
* 🧭 **Умная навигация**: Поддержка истории назад/вперёд (`Alt+Left` / `Alt+Right`, боковые кнопки мыши) и открытие внешних ссылок в системном браузере.
* 🛡 **Автоматическое восстановление**: Автономный экран переподключения при разрывах сети с кнопками повторной попытки и мгновенного перехода на зеркало.
* 📦 **Поддержка установщиков**: 
  - macOS: `.dmg` и `.zip` (Apple Silicon arm64 + Intel x64) с нативным `hiddenInset` стилем;
  - Windows: `.exe` (NSIS-установщик);
  - Linux: `.deb` (Debian, Ubuntu, Linux Mint) и портативный `.AppImage`.

## Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + R` / `Cmd + R` | Перезагрузить приложение |
| `F12` | Открыть / закрыть DevTools (инструменты разработчика) |
| `Alt + ←` | Назад в истории навигации |
| `Alt + →` | Вперёд в истории навигации |
| `Ctrl + +` / `Ctrl + -` | Увеличение / уменьшение масштаба |
| `Ctrl + 0` | Сброс масштаба на 100% |
| `F11` | Полноэкранный режим |

## Быстрый старт разработчика

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm start
```

### 3. Конфигурация мода (`iskra.config.json`)
Укажите ваш ключ разработчика, созданный на портале [https://iskraai.pages.dev/api-keys](https://iskraai.pages.dev/api-keys):

```json
{
  "clientName": "Iskra Desktop Client",
  "clientVersion": "0.7.1",
  "targetPlatform": "desktop",
  "webUrl": "https://iskraai.pages.dev",
  "apiUrl": "https://bacand-iskra.onrender.com",
  "clientKey": "iskra_app_live_YOUR_KEY_HERE"
}
```

### 4. Сборка установщиков
```bash
# Сборка macOS DMG & ZIP (Apple Silicon arm64 + Intel x64):
npm run build:mac

# Сборка Windows EXE:
npm run build:win

# Сборка Linux DEB & AppImage:
npm run build:linux
```
Готовые установщики появятся в папке `dist/`.

### 5. Установка на Linux (Ubuntu / Debian / Mint)
```bash
sudo dpkg -i dist/iskra_0.7.1_amd64.deb
```
