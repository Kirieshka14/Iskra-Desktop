# Iskra Desktop (Windows EXE & Linux DEB)

Официальный открытый десктопный клиент платформы интерактивного сторителлинга **Iskra**, созданный на базе **Electron** под свободной лицензией **GNU AGPLv3**.

Этот репозиторий предназначен для сборки официального приложения Iskra под Windows и Linux, а также для создания пользовательских модов сообщества.

---

## Возможности клиента

* 🖥 **Нативное окно без рамок браузера**: Чистый тёмный интерфейс, плавная прокрутка, отсутствие отвлекающих элементов.
* ⚡ **Автоматическая инъекция Client Key**: Заголовок `X-Iskra-Client-Key` автоматически передаётся во все сетевые запросы приложения.
* 🔒 **Полная синхронизация**: Все диалоги, история и баланс сообщений синхронизируются в реальном времени с веб-версией и мобильным приложением.
* 📦 **Поддержка установщиков**: Сборка `.exe` (NSIS-установщик и Portable для флешек) и `.deb` (для Ubuntu/Debian).

---

## Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm start
```

### 3. Конфигурация мода (`iskra.config.json`)
Укажите ваш ключ разработчика, полученный на странице [https://iskraai.run.place/api-keys](https://iskraai.run.place/api-keys):

```json
{
  "clientName": "Iskra Desktop Edition",
  "webUrl": "https://iskraai.run.place",
  "apiUrl": "https://bacand-iskra.onrender.com",
  "clientKey": "iskra_app_live_YOUR_KEY_HERE"
}
```

### 4. Сборка установщиков
```bash
# Сборка Windows EXE:
npm run build:win

# Сборка Linux DEB & AppImage:
npm run build:linux
```
Готовые установщики появятся в папке `dist/`.
